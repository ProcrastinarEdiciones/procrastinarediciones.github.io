# Procrastinar Ediciones

Sitio estático en español. No requiere instalación ni compilación.

Para revisar localmente, ejecuta `python3 -m http.server 8000` en este directorio y abre http://localhost:8000.

## GitHub Pages

1. Añade los archivos de este directorio a la raíz de la rama `main`.
2. En el repositorio, abre **Settings → Pages**.
3. En **Source**, elige **Deploy from a branch**, selecciona `main` y `/(root)`, y guarda.
4. Al terminar el despliegue, abre la URL que muestra GitHub Pages y verifica que carguen la portada y los recursos.

El apartado Contacto indica que el canal editorial se publicará más adelante.
